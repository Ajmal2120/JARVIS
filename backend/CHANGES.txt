DATE: 2026-06-29
FILE: backend/voice/stt.py
CHANGE: Replaced Vosk STT with faster-whisper (medium model) + silero-vad
REASON: Much better accuracy, auto-detects Hindi/Hinglish natively
DETAILS:
  - Model upgraded from tiny → medium (better accuracy)
  - Language fixed "en" → None (auto-detect)
  - Added silero-vad for speech segment detection
  - Yields complete utterances only (no partials/hallucinations)
  - CUDA auto-detection with CPU fallback
  - Same public API maintained (start_listening, stop_listening, etc.)

---

DATE: 2026-06-29
FILE: backend/voice/tts.py
CHANGE: Replaced edge-tts with Kokoro TTS (fully local, no internet)
REASON: Offline capable, faster, multilingual
DETAILS:
  - No subprocess, no temp files, no internet required
  
  - Auto-detects English vs Hindi via Devanagari chars + keyword heuristic
  - Default voice: af_heart (English), hi_0 (Hindi)
  - Plays via sounddevice directly (numpy float32 → int16)
  - Legacy API: synthesize_bytes(text, voice=None) maintained

---

DATE: 2026-06-29
FILE: backend/tts/speaker.py
CHANGE: Replaced edge-tts with Kokoro TTS
REASON: Same as above - offline, fast, multilingual
DETAILS:
  - Legacy API compat maintained: synthesize(), speak(), list_voices()
  - Kokoro engine loaded lazily (one-time, cached)
  - MODULATION dict kept as no-op (Kokoro handles speed differently)
  - synthesize_bytes() returns raw float32 PCM (24kHz mono)

DATE: 2026-06-29
FILE: backend/brain/intent.py
CHANGE: Created new intent detection engine
REASON: Zero-latency for simple commands (no Claude API call needed)
DETAILS:

  - Pattern-based matching (no LLM)
  - Returns {type, target, response}
  - Commands checked: time queries, volume commands, app launching, media play, screenshot, lock/restart

SECTION 4: OS-LEVEL CAPABILITIES ADDED
================================================================================

The following OS-level capabilities are now available to JARVIS:

1. SCREEN READING
   - capture_screen(region=None) → PIL Image
   - ocr_text(image) → list of (text, bbox)
   - capture_window(window_title) → PIL Image
   - get_all_windows() → list of WindowInfo

2. GUI AUTOMATION
   - find_and_click(text) → bool
   - type_in_field(field_text, text) → bool
   - click_at_position(x, y)
   - activate_window(title)

3. MOUSE CONTROL
   - move_to(x, y, duration=0.2)
   - click(x, y, button='left')
   - double_click(x, y)
   - right_click(x, y)
   - drag(start_x, start_y, end_x, end_y)
   - scroll(amount)

4. KEYBOARD CONTROL
   - type_text(text, interval=0.01)
   - press(key), hotkey(*keys)
   - enter(), escape(), tab(), backspace()
   - ctrl_a(), ctrl_c(), ctrl_v()

5. WINDOW MANAGEMENT
   - get_window_by_title(title, partial=True) → hwnd
   - activate_window(hwnd) → bool
   - get_all_windows() → list[WindowInfo]

FILE: backend/voice/stt.py
CHANGE: Optimized for faster processing and lower latency
REASON: User requested faster response times
DETAILS:
  - Model changed from 'small' → 'tiny' (39MB vs 461MB, 3x faster)
  - CHUNK_SIZE reduced from 1s → 0.5s for faster response

  - Added real-time transcription logging (RMS, processing duration)
